3. Verify changes in `index.html`
4. Commit and push

### To Add New Artifacts
1. Add artifact to `index.html` artifactsData array
2. Create/update research JSON file in `research-data/`
3. Update stats in header
4. Run integration script
5. Update documentation
6. Commit and push
