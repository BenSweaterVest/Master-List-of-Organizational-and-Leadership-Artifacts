# Master List of Organizational and Leadership Artifacts

A comprehensive catalog of 193 organizational and leadership artifacts used across public administration, nonprofit leadership, and general organizational management.

## Overview

Organizations do not fail because they lack documents. They fail because their documents do not connect. This repository catalogs the strategic, operational, and governance artifacts that form the foundation of effective organizational management, with particular attention to how these documents integrate across the organizational architecture.

## Access the Interactive Catalog

**View the full catalog:** Open `index.html` in your browser for the complete interactive experience.

The website includes:
- Search and filter functionality (by sector, category, or keyword)
- Detailed information for all 193 artifacts
- Academic research links and real-world examples
- Bookmark and priority management system
- Export and sharing capabilities
- Mobile-responsive design

**Relationship visualization:** Open `relationships.html` to see how artifacts connect and depend on each other across all categories.

## The Strategic Coherence Framework

Despite different terminology across sectors, nearly all organizations rely on the same core architecture that flows from identity through accountability:

```
Identity → Direction → Priorities → Action → Accountability
```

This framework is implemented through specific artifacts:

```
Vision & Mission → Guiding Principles/Values → Strategic Goals → Initiatives/Plans → Performance Metrics
```

### The 7 Core Artifacts

Every other organizational document depends on these foundational artifacts:

1. **Purpose Statement** - Why we exist (most stable)
2. **Vision Statement** - Where we are going (aspirational)
3. **Mission Statement** - What we do today (operational)
4. **Core Values** - How we behave (cultural)
5. **Guiding Principles** - How we decide (framework)
6. **Strategic Goals** - 3-5 year targets (priorities)
7. **Strategic Priorities** - Current focus areas (resource allocation)

## Integration Architecture

Understanding how artifacts relate across organizational layers is critical for strategic coherence:

| Layer | Function | Stability | Key Artifacts |
|-------|----------|-----------|---------------|
| **Identity** | Defines essence | Permanent | Purpose, Vision, Mission, Values |
| **Direction** | Decision criteria | Long-term | Guiding Principles |
| **Priorities** | Resource focus | 1-5 years | Strategic Goals & Priorities |
| **Action** | Delivery | Annual | Plans & Initiatives |
| **Accountability** | Validation | Ongoing | Performance Metrics |

## Key Insights

**Universal Structure, Different Drivers:** While motivational drivers differ profoundly across sectors (profit for business, mission for nonprofit, mandate for public sector), the structure of effective organizational management remains remarkably similar.

**Strategy-to-Performance Gap:** Organizations typically achieve only 70% of their strategy's potential due to poor execution. Effective artifacts bridge this gap by providing clarity, ensuring alignment, and enabling accountability.

**Document Governance Required:** Documents must be actively governed, not merely created. The stable foundation (Purpose, Values) must dictate the adaptive structure (Operating Model, Theory of Change), which must dictate measurement (KPIs, Evaluation).

**Cross-Sector Literacy:** Modern leadership increasingly requires understanding artifacts across sectors. Public administrators must grasp business cases for partnerships; consultants must understand Theories of Change for social enterprise clients; nonprofit leaders must understand legislative processes for advocacy.

## Using This Repository

### Quick Start

1. Open `index.html` in any modern web browser
2. Use the search bar to find specific artifacts
3. Filter by sector (Public, Nonprofit, General) or category
4. Click artifact names to view detailed information
5. Bookmark frequently referenced artifacts
6. Access research links for deeper learning

### Advanced Features

**Bookmarking System:** Save artifacts and assign priority levels (Immediate, Mid-term, Long-term). Export your collection to JSON or share via URL.

**Research Integration:** Each artifact includes curated links to academic articles, framework documentation, and real-world examples.

**Relationship Mapping:** Explore the network visualization (`relationships.html`) to understand how artifacts connect and depend on each other.

**Offline Access:** The catalog works offline and can be installed as a Progressive Web App (PWA) on mobile devices.

## Technical Details

**No Installation Required:** Both `index.html` and `relationships.html` are self-contained files that run entirely in the browser with no dependencies.

**Data Format:** Artifact data is embedded as JSON within the HTML files for portability and offline access.

**Browser Compatibility:** Works in all modern browsers (Chrome, Firefox, Safari, Edge).

## Methodology

Artifacts are organized by functional purpose and ordered from foundational to specialized within each category. Each entry includes:

- Name
- Purpose (what it is for)
- Example (well-known or generic)
- Applicable sectors
- Contextual notes (relationships to other artifacts)
- Research links (academic and practical)
