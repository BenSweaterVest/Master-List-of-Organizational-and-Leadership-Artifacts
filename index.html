The Strategic Foundation (Identity Layer)

Purpose (stable) → Vision (aspirational) → Mission (operational) → Values (behavioral)
  • • Purpose: "Why do we exist?"
  • • Vision: "Where are we going?"
  • • Mission: "What do we do?"
  • • Values: "How do we behave?"

The Universal Artifact Stack

Identity → Direction → Priorities → Action → Accountability Vision & Mission → Guiding Principles/Values → Strategic Goals → Initiatives/Plans → Performance Metrics
  • • Vision Statement - Aspirational future state (Identity)
  • • Mission Statement - Current purpose and operations (Identity)
  • • Core Values - Behavioral expectations and culture (Direction)
  • • Guiding Principles - Decision-making frameworks (Direction)
  • • Strategic Goals - Major 3-5 year objectives (Priorities)
  • • Strategic Priorities - Current focus areas for resource allocation (Priorities)
