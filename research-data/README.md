# Research Data

This directory contains curated research for all 188 organizational and leadership artifacts.

## Files Structure

Each JSON file contains research for a range of artifacts with two links per artifact:
- **explanationLink**: Academic or authoritative source explaining the artifact
- **exampleLink**: Real-world example or template

## Source Quality Standards

All research sources prioritize academic rigor:
- **.edu domains** - Universities and academic institutions
- **.gov domains** - Government agencies and official resources
- **Professional organizations** - PMI, SHRM, NASW, OECD, etc.
- **Standards bodies** - ISO, NIST, COSO, etc.

## Integration

These files are integrated into `index.html` using the `integrate_research.py` script at the root of the repository.

**Note:** Artifacts 1-10 have their research directly embedded in `index.html` and do not have separate JSON files.
